## Software User Groups

Any model can be used in an exploratory way to support a DMDU approach. But, some are better suited than others. [VisionEval](https://visioneval.github.io/) is a strategic modeling platform that facilitates testing across an array of inputs and policies and provides various outputs. [TMIP-EMAT](https://tmip-emat.github.io/tmip-emat/dev/) can be connected with any model, including VisionEval, to design efficient experiments across ranges of uncertainty, run the model, and produce meta-models useful for visualizing or scenario discovery tools.

If you are an active user of these tools and would be willing to serve as an “ambassador” to assist new users, let us know and we will compile that list here.

### TMIP-EMAT

TMIP-EMAT is not being actively supported by FHWA, but is in use. Responses to a 2024 survey of 14 users is [available here](https://docs.google.com/document/d/1l0vJ2wPVVDZ8GuRTMwf3ZwI7_QiVqFmrkyQ-0Gp9EDw/edit?tab=t.0#heading=h.9lpkdii4qrzf).
