Any model can be used in an exploratory way to support a DMDU approach &mdash; but some are better
suited than others. Two tools anchor most of the work happening in this space today.

<div class="dl-card-grid">
  <div class="dl-card">
    <h3><a href="https://visioneval.github.io/">VisionEval</a></h3>
    <p>A strategic modeling platform that facilitates testing across an array of inputs and
    policies and reports on outputs across all of them &mdash; built for scenario breadth rather
    than facility-level detail, which is exactly what makes it fast enough to run at exploratory
    scale.</p>
  </div>
  <div class="dl-card">
    <h3><a href="https://tmip-emat.github.io/tmip-emat/dev/">TMIP-EMAT</a></h3>
    <p>Exploratory Modeling and Analysis Tool. Connects to any model &mdash; including VisionEval
    &mdash; to design efficient experiments across ranges of uncertainty, run the model, and
    produce meta-models useful for visualizing or scenario-discovery tools.</p>
    <p style="margin-top:0.75rem; font-size:0.9rem; color:var(--dl-ink-soft);">TMIP-EMAT is not
    actively supported by FHWA, but is in active use. Responses to a 2024 survey of 14 users are
    <a href="https://docs.google.com/document/d/1l0vJ2wPVVDZ8GuRTMwf3ZwI7_QiVqFmrkyQ-0Gp9EDw/edit?tab=t.0#heading=h.9lpkdii4qrzf">available here</a>.</p>
  </div>
</div>
